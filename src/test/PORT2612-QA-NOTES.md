**Native `the_sift_tests:mc2612_all_legacy_structures_nbt`**

- Test file `Sift2612StructureGameTests.java`; fixture `src/test/resources/the_sift_tests/fixtures/official-262-structure-ids.json`. The original262 source contains **296** The Sift structure NBTs: **217** legacy DataVersion 4903 with `Name`/ `Properties` and **79** Sculkers Lair parts DataVersion 5023 with lowercase `id`/ `properties`. Three additional official `data/minecraft/structure/ancient_city/city_center/city_center_{1,2,3}.nbt` overlays have DV 4903 and `the_sift:sonorous_deepslate`. Total **299** assets checked.
- The actual MC26.1.2 `NbtUtils.readBlockState` recognizes **only** `Name`/`Properties` (not the 5023 lowercase `id` schema). Data worker must normalize the **79** Lair structures to the target without dropping their original block palette; the native test intentionally does **not** require that the original 5023 DataVersion survives conversion.
- The server-side GameTest resolves all **299 IDs** through the actual `ServerLevel.getStructureManager().get` (exact MC26.1.2 method), checks positive native geometry, actual decoded block placements, and non-AIR palette after `StructureTemplate.save`. Every formerly 5023 Lair piece must retain a block ID beginning with `the_sift:`; the three Minecraft Ancient City overlays must each retain `the_sift:sonorous_deepslate`. This detects silent AIR fallback from wrong NBT field names and missing overlay assets.
- An additional check in the **same** native test reads all **299 raw** `<namespace>:structure/<path>.nbt` resources from the active server `ResourceManager` with target `NbtIo.readCompressed` and validates **every** state of `palette` or all `palettes`: `Name` must parse as a registered `BuiltInRegistries.BLOCK` ID, every `Properties` key must exist in that block's `StateDefinition`, and `Property.getValue(value)` must accept the string. Invalid, silently discarded orientation/waterlogging and unknown target blocks now produce a real GameTest failure with template/block/property details, not a skipped state. The test does not place templates or launch a Sift dimension. Additional target-only structures are not assumed absent.

**Native `the_sift_tests:mc2612_all_sift_biomes_preserve_spawns`**

- Test file `Sift2612BiomeSpawnGameTests.java`; fixture `src/test/resources/the_sift_tests/fixtures/official-262-biome-spawns.json`, frozen from the official **11** biome JSONs, including full category lists, creature-generation probabilities and per-entity costs.

Spawn order is intentionally irrelevant (compare sorted full multisets), so equivalent native builder ordering is not misclassified as a gameplay regression. `corrupted_sift` intentionally has **zero creature and three monster** entries.
